VTX — — Open snapshot

Drone camera → FC video transmitter (5917 MHz, 25 mW) → RC832 (set to 5-8) → USB capture stick → Pi → here. SNOW = RC832 hears nothing on its channel (drone battery out, wrong channel). FLAT = blank screen. NO INPUT = capture stick stuck (auto-resets, or press Reset). Motor safety (Space = STOP) still works on this tab.
Video OFF puts the drone's video transmitter in pit mode (near-zero output) to save battery and heat; the camera itself stays powered (it's hard-wired). Not saved: unplugging the battery turns video back ON. Needs the FC on USB. Turning video off is refused while armed.

Radio (Pocket) arming

The dashboard blocks arming while it controls motors. Allow it to arm with SA and fly the motors from the Pocket sticks (props off!). Reconnecting re-blocks.

Closing/hiding this tab, losing the server, unplugging USB or arming the FC stops everything and disables control. If a motor ever keeps spinning, unplug the battery.

1000 = stop. 1100 ≈ 10 % throttle = this FC's armed idle. Values below ~1060 can stutter (ESC loses sync) — that's normal, not a fault. Arrow keys nudge the master slider.

What Betaflight is commanding each ESC (from the sliders, or the mixer when armed with the Pocket), as % throttle. Real RPM needs bidirectional DShot (off on this FC), so it shows here only if that is enabled.

Motor direction (stored in each ESC)

Look from above. Betaflight default (props in): M1 & M4 clockwise, M2 & M3 counter-clockwise. If a motor turns the wrong way, press the other button for it (try “Reversed”; if it was already reversed, “Normal” flips it back), then spin-test it again.
