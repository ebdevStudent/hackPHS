CAD approach: 

- Scale the Thingiverse design to the current ~245–250 mm outer cage target, but do not uniformly scale hardware features.



- Keep the outer cage + 2-ring gimbal, replace the center with the current Apex-2 quad, resize rod sockets/bearing/pivot holes for the actual parts, and verify full prop clearance through all gimbal positions.





FINAL CAD RULES

- Design the P1A fixed-cage center mount first; make gimbal rings removable so P1B can be added without redesigning the aircraft.

- Keep X/Y quad and battery position adjustable for center-of-gravity balancing.

- Model every prop disk through the full mechanically reachable gimbal range; allow zero cage/ring/wire intrusion.

- Protect both camera field of view and propeller inflow/outflow.

- Minimize TPU/hub volume; use 1 mm rods by default and reinforce with 1.5 mm only where testing shows flex.

- Use a strap-style battery mount that can accept the planned 2S test range instead of a tight tray.

- Track estimated cage/gimbal mass before printing.
